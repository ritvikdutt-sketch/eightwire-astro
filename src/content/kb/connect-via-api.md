As a service, we can support you if you require to use API's to connect.

Our current version of Eightwire does not have an SDK that can be used as an intermediate component — a proxy application needs to be built.

On application to [support@eight-wire.com](mailto:support@eight-wire.com) we can provide a sample written in C# that executes a series of processes.
